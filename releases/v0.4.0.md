# PassKhadam v0.4.0 — Cloud Staging & Verifiable Credential Architecture

### Summary
PassKhadam v0.4.0 is a major milestone introducing full production cloud staging on Render and Supabase, live Ethereum Sepolia contract integration, multi-trade worker selection, decoupled immutable employment history, dynamic multi-authority credential issuance, and streamlined desktop UI.

### What's New in v0.4.0:
1. **Cloud Staging & Sepolia Testnet Integration**:
   - Backend web service deployed and live on Render: `https://passkhadam-api.onrender.com`
   - Authoritative relational database hosted on PostgreSQL (Supabase).
   - Smart contracts deployed to Ethereum Sepolia testnet (`WorkerIdentityRegistry`, `EmploymentRegistry`, `CredentialRegistry`, `WelfareSchemeRegistry`, `OrganizationRegistry`).
   - Pinata IPFS cloud gateway integration for decentralized encrypted credential pinning.
   - Resend email OTP and activation link delivery.
2. **Dynamic Credential Issuance & Customization**:
   - Replaced static mock credential cards with persistent database models (`DBWorkerCredential`) and verifiable credentials.
   - **Government Officers** can issue custom credentials directly to worker wallets (e.g., BOCW Registration, Skill Development Mission, Health Scheme Eligibility) with issuing authority, category, and expiry dates.
   - **Employers** can issue verified trade and site experience credentials (e.g., Heavy Machinery Safety, Advanced Welding Stint, Site Supervisor Recommendation).
   - Rich SSI credential cards with role badges, verification status, and cryptographic DID anchors.
3. **Multi-Trade Worker Registration**:
   - Migrant workers can select their authentic trade/profession during registration and onboarding (Electrician, Plumber, Carpenter, Mason, Welder, Painter, Driver, Construction Labourer, Heavy Machinery Operator, Tailor, Security Guard).
   - Selection dynamically populates trade skills and portable employment profile.
4. **Decoupled Immutable Employment History (Invariant Fix)**:
   - Worker employment stints and contracts are persisted in PostgreSQL (`DBEmployment`).
   - Revoking or discontinuing an employer's category authorization revokes *future* contract creations while guaranteeing that all existing, previously anchored employment history remains permanently immutable, tamper-proof, and visible in the worker's portal.
5. **Streamlined UI & Cloud Status**:
   - Replaced legacy local Web3 ("Connect Wallet" / "EVM: 1337 • IPFS") header icons with a sleek "Cloud Staging • Sepolia" status badge.
   - Main process strict origin enforcement (`app://passkhadam.app`).
   - Cleaned repository files, removed untracked IPFS blobs, and integrated automated GitHub sync scripts.
