# PassKhadam v0.3.0 — Portable Desktop Distribution Milestone

### Summary
PassKhadam v0.3.0 marks the initial portable desktop release of the Decentralized Self-Sovereign Identity (SSI) and Cross-State Welfare Portability Platform for interstate migrant workers.

### Highlights & Key Features:
- **Portable Windows Executable**: Zero-dependency standalone packaging via Electron (`PassKhadam-Portable-0.3.0.exe`). No Node.js or Python runtime required on client machines.
- **5-Role Unified Multi-Portal Experience**: Single desktop interface dynamically switching between Migrant Worker, Registered Employer, State Government Officer, Platform Admin, and UIDAI / Mock Aadhaar Authority.
- **Cryptographic Zero-Knowledge & Zero-PII Guarantees**: Demographic identity encrypted off-chain via AES-256 before pinning to IPFS; on-chain smart contracts anchor only DID hashes and cryptographic proofs, adhering strictly to India's DPDP Act 2023.
- **Anti-Duplicate Benefit Portability**: Smart contracts verify eligibility and enforce strict cooldown timers to prevent double-spending of rations, emergency medical funds, and BOCW welfare across state boundaries.
- **Voice Narration & Multi-Language Accessibility**: Text-to-speech audio guidance in Hindi, Kannada, Tamil, Telugu, and English to bridge digital literacy barriers for blue-collar workers.
